# Live two-account demo video script

Target length: 2:50. This walkthrough uses the connected Twitch accounts directly; it does not use **Run full demo**.

## Roles and recording setup

- **msaimanish** is Channel A, the source channel. It starts the quest and raids the other channel.
- **krishnatejabommipati** is Channel B, the receiving channel. Its preview is the main viewer-facing overlay for the welcome and story outcome.
- Keep both Twitch accounts signed in at once using separate browser profiles or browsers. Use msaimanish's chat for the source-channel name/vote and for the raid command. After the raid, use its account in Channel B chat for `!join` and its incoming-party vote; use krishnatejabommipati's account for the local vote.
- Open the **msaimanish dashboard** and the **krishnatejabommipati dashboard**. In the krishnatejabommipati dashboard, click **open preview**. Arrange the source dashboard and receiving preview side by side for the start; give the receiving preview most of the screen for the raid welcome and outcome.
- Make sure the two Twitch accounts are authorized, the backend is running with live Twitch enabled, and both channels are configured. Do not use demo-mode inputs. For a quicker recording, set `NAMING_WINDOW_SECONDS=15` and `WELCOME_HOLD_SECONDS=25` in the root `.env`, then restart `pnpm dev`. Keep credentials, tokens, and dashboard/overlay URLs out of frame.
- Prepare a real raid from msaimanish to krishnatejabommipati. The raid viewer count may be small; show the actual count the app receives and never substitute the demo's 37 viewers.

## Important recording checks

- This is a live path, so do not show the **SIMULATED** label or claim any simulated value is live. Use the actual raid count and the real chat messages visible during the recording.
- Only one vote per account counts in each round. Avoid sending `!join` from the host account; it would opt that account into the incoming-party cohort.
- The app may advance automatically when the welcome hold expires. Click **Open beat 2 voting** promptly if it is still available; otherwise use the active vote window and close it with **Close voting now**.
- If a real raid, chat event, AI recap, or faction tally does not appear, stop and troubleshoot rather than narrating it as if it happened. For a fallback-only recap, say that the deterministic template appeared instead of saying NVIDIA generated it.
- Do not use **Run full demo** in this recording. Do not show `.env`, `.data/twitch-tokens.json`, dashboard tokens, overlay keys, or Twitch credentials.
