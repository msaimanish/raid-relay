# Live two-account demo video script

Target length: 2:40. This is a manual live walkthrough using both connected Twitch accounts. Do not use **Run full demo**.

## Before recording

- Start `pnpm dev`. Confirm live Twitch is connected for both configured channels.
- Keep **msaimanish** signed in as Channel A, the source, and **krishnatejabommipati** signed in as Channel B, the receiving channel. Use separate browser profiles or browsers so both chats can stay open.
- Open the **msaimanish dashboard** and **krishnatejabommipati dashboard**. On the receiving dashboard, click **open preview**. Keep the receiving preview as the main viewer-facing view for the raid welcome and story outcome.
- Open each channel's Twitch chat using Twitch's **Popout Chat** option. Keep both chat windows visible during the command portions so viewers can see the messages arrive in Twitch chat.
- In the first shot, show both Twitch channel pages side by side with each channel name and **LIVE** badge visible. Then switch to the app layout while keeping both pop-out chats on screen.
- For a quick recording, set `NAMING_WINDOW_SECONDS=15` and `WELCOME_HOLD_SECONDS=25` in the root `.env`, then restart `pnpm dev`. Keep credentials, `.env`, dashboard tokens, and overlay keys out of frame.
- Ensure no quest is active in the source dashboard. If the previous quest is completed, the start button is **Start another quest**; if no quest exists, it is **Start quest**.
- Arrange Twitch chat as evidence of real messages; use actual account messages. Never narrate a simulated event or party count as live.

## Recording checks

- Show both Twitch **LIVE** badges in the opening and keep the relevant pop-out chat visible whenever commands are entered.
- The actual raid count may be zero to two. State the exact displayed value; do not replace it with the simulated demo's 37. The rules use small for 1–9, medium for 10–49, and large for 50 or more; zero is preserved and treated as small.
- Use **Raid Now** in the Twitch raid dialog rather than waiting for its countdown.
- Only say the recap was generated by NVIDIA AI if the dashboard actually shows **Recap source: ai** in that take. Otherwise use the fallback narration above.
- Run `pnpm test` before recording the Codex segment. Show it as passing only if it passes in that recording environment. If loopback tests fail with `listen EPERM`, show or describe the result accurately instead of calling the full suite green.
- If the live raid, chat events, recap source, or faction split does not appear, stop and troubleshoot. Do not narrate a feature as live if the footage does not show it.
- Do not show `.env`, `.data/twitch-tokens.json`, dashboard/overlay keys, or credentials. Keep the entire final video under three minutes.
